# API Testing Overview

## Introduction

This repository contains a collection of API Testing projects created to demonstrate practical Software Quality Assurance (QA) skills in testing RESTful APIs using industry-standard tools and workflows.

The projects cover the complete API testing process, from understanding API documentation and analyzing endpoints to designing test cases, executing requests, automating validations, and reporting defects.

The primary goal of this repository is to build a professional API Testing portfolio while learning best practices used in real software development environments.

---

# Objectives

The objectives of this repository are to:

- Practice REST API Testing using real-world APIs
- Design structured API Test Plans, Test Scenarios, and Test Cases
- Perform Manual API Testing using Postman
- Build API automation using Postman Test Scripts
- Validate API requests and responses
- Produce professional QA documentation
- Simulate real-world API testing workflows
- Build a portfolio suitable for Junior QA and API QA positions
