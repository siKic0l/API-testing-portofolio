# Project Overview

This project demonstrates an end-to-end API Testing workflow using the **Restful Booker API**.

The project is designed to simulate how API testing is performed in a real software development environment, covering the complete Software Testing Life Cycle (STLC) from API analysis to automated test execution.

Unlike simple Postman request collections, this repository documents the complete QA process, including planning, test design, execution, automation, reporting, and defect management.

---

# Project Objectives

The objectives of this project are to:

- Understand REST API architecture.
- Analyze API specifications.
- Design API test scenarios.
- Create structured API test cases.
- Perform manual API testing.
- Build reusable Postman collections.
- Implement Postman automation scripts.
- Manage API testing using Qase.io.
- Produce professional testing documentation.

---

# Why Restful Booker?

Restful Booker is one of the most widely used public APIs for learning REST API Testing.

It provides realistic hotel booking functionality including authentication, CRUD operations, validation, and authorization, making it an excellent practice environment for Quality Assurance Engineers.

The API is commonly used for:

- API Functional Testing
- Postman Practice
- REST Assured Practice
- API Automation
- Interview Preparation
