# Postman Public Documentation

## Overview

This document provides access to the public API documentation generated from the Postman Collection used in this project.

Publishing the collection through Postman allows the entire API documentation to be shared in a professional, interactive, and easily accessible format without requiring users to import the collection manually.

The published documentation serves as the primary reference for understanding the available endpoints, request parameters, authentication requirements, sample requests, and expected responses.
